## 收录范围与改动

收录全部 26 个专题的 `SKILL.md`（以及 `sw-workflow/terms.md`）。各专题下的 `reference*.md`（50 个）不随本仓库分发，需要时运行 `scripts/fetch-references.sh`（或 Windows 上的 `scripts/fetch-references.ps1`）从原仓库下载同一固定版本，并按 `scripts/screenwriting-references.sha256` 校验。原文件 `SKILL.md` 改名为 `GUIDE.md`，避免在 writing-studio 内被注册为独立 skill；其余内容未改动。

最新版本、问题反馈和贡献请前往原仓库。
