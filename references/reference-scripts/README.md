# 参考剧本与模板

| 文件 | 用途 |
|---|---|
| `chinese-screenplay-template.md` | 中文影视剧本（场号制）模板 |
| `screenplay.fountain` | 英文 spec 剧本 Fountain 模板 |
| `video-script-template.md` | 视频口播稿（多栏格式）模板 |
| `shot-list.md` / `shot-list.csv` | 分镜表模板（Markdown 用于审阅，CSV 便于脚本和表格软件处理） |
| `series-bible.md` | 剧集圣经模板 |
| `style-bible.md` | 视觉风格圣经模板（AI 视频生成时保持人物和画面一致） |

`screenplay.fountain`、`shot-list.*`、`series-bible.md`、`style-bible.md` 来自 [DenisHumen/cinema-skills](https://github.com/DenisHumen/cinema-skills)（MIT），许可证见 `../library/cinema/LICENSE`。

## 放入你自己的参考样稿

把你喜欢的剧本、口播稿、文章样稿放在这个目录下，例如 `samples/某频道-口播-01.md`。写作时告诉 Claude"参考 samples/xxx 的风格"，它会学习样稿的句长、用词和节奏，但不会照搬其中的内容。
