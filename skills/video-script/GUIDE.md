# 视频稿件：风格、口播、分镜

覆盖短视频（抖音、TikTok、Reels、视频号）、中长视频（YouTube、B站）、口播稿、解说词、纪录片旁白、Vlog、分镜表和 AI 视频生成提示词。

## 1. 立项卡

动笔前先填好这张卡，缺项就问：

```markdown
- 平台与画幅：抖音 9:16 / B站 16:9 / ……
- 时长：
- 类型：口播 / 解说 / 剧情 / 纪录 / 混剪 / AI 生成
- 风格：styles/ 中的哪一个，或用户样稿
- 目标观众与他们已有的认知：
- 核心观点（一句话）：
- 观众看完要做的事：关注 / 评论 / 点链接 / 记住一个观点
- 素材：已有文稿、数据、画面、B-roll
```

## 2. 结构模板

**短视频（15–90 秒）**

| 段 | 时长 | 内容 |
|---|---|---|
| 钩子 | 0–3 秒 | 反常识结论、具体数字、冲突画面或直接点题。不以"我"开头，不铺垫 |
| 展开 | 3–20 秒 | 一个场景或问题，让观众代入 |
| 干货 | 20 秒–结尾前 | 最多 2 个要点，每点配一个具体例子 |
| 收尾 | 最后 3–5 秒 | 落回钩子，给一个明确动作。只有真有东西可发时才写"评论 XX 领取" |

**中长视频（5–20 分钟）**

冷开场（30 秒内交代"这期回答什么问题"）→ 背景 → 3–5 个章节，每章开头一句话预告、结尾一个小悬念 → 高潮/反转 → 总结 → 片尾互动。每 60–90 秒安排一次节奏变化：换画面、换讲法、抛问题或插一个梗。

**纪录片 / 人文解说**：用 `styles/documentary.md`，按"场景 → 人物 → 事件 → 意义"推进，旁白给画面留白，不念画面上已有的信息。

钩子写法和题材库见 `references/library/social-media/hook-generator/GUIDE.md`；Reels 结构和口播规则见 `library/social-media/reels-scripting/GUIDE.md`；YouTube 脚本、留存曲线、标题缩略图见 `library/marketing/video/GUIDE.md` 和 `library/social-media/youtube-thumbnail/GUIDE.md`。

## 3. 口播稿写法

- 写给耳朵听：短句，一句一个信息；数字读得出来（"三成"比"31.7%"好念，必要时上屏显示精确值）。
- 口语但不油：可以用"你""咱们"，少用书面连接词"此外、综上所述"。
- 每句都要能配画面。写不出画面的句子，要么删，要么改成能看见的说法。
- 标出停顿和重音：`/` 短停，`//` 长停，**加粗** 为重音。
- 语速估算：中文口播约 4–5 字/秒，按目标时长控制字数（60 秒 ≈ 250–300 字）。

口播稿用多栏格式（完整模板 `references/reference-scripts/video-script-template.md`）：

| 时间 | 口播/旁白 | 画面 | 字幕/花字 | 音效/音乐 |
|---|---|---|---|---|
| 00:00–00:03 | …… | …… | …… | …… |

## 4. 分镜

从定稿的脚本或剧本拆分镜，参考 `references/library/ai-storyboard/director-storyboard.md` 和 `library/cinema/`。

**拆镜规则**

- 动作变化、情绪转折、场景切换都要另起一个镜头。
- 单镜头对白超过 15 秒就要切，长对话至少用 2–3 种景别交替。
- 守住 180° 轴线和运动方向，连续性备注写清服装、道具、光线。

**分镜表**（模板 `references/reference-scripts/shot-list.md`，CSV 版 `shot-list.csv`）

| 镜号 | 景别 | 角度 | 运镜 | 时长 | 画面内容 | 台词/旁白 | 声音 | 转场 |
|---|---|---|---|---|---|---|---|---|

景别：大远景 EWS / 全景 WS / 中景 MS / 近景 MCU / 特写 CU / 大特写 ECU / 插入 INS / 过肩 OTS / 主观 POV。
运镜：固定、推、拉、摇、移、跟、升降、手持、环绕。

**画面与旁白的衔接**

- 旁白讲"为什么"，画面给"是什么"，两者不重复。
- 关键句落在画面切点上；情绪段让画面先走、旁白后到。
- 需要观众看清的信息（数据、地名、人名）上屏，不只靠嘴说。

## 5. AI 视频生成

需要给 Midjourney、可灵、Runway、Sora 等工具出提示词时：

- 先建风格圣经 `references/reference-scripts/style-bible.md`，固定人物外观、色调、画幅、镜头语言，每个提示词都遵守它。
- 每镜输出两份：关键帧图像提示词，以及视频提示词（主体、动作、运镜、光线、氛围、时长）。
- 表情与微动作、多模态提示词、一致性交叉审查的细则见 `library/ai-storyboard/` 下的 `ai-video-studio.md`、`micro-expression-engine.md`、`multimodal-prompt.md`、`cross-audit.md`。
- 完整制作流水线（剧本 → 风格 → 分镜 → 生成 → 剪辑 → 调色 → 声音）见 `library/cinema/00-pipeline/README.md`。

## 6. 视频线的质检重点

- 前 3 秒有没有给出观看理由
- 时长和字数是否匹配
- 每个事实、数字有没有来源（走 `skills/research-and-factcheck/`）
- 口播是否顺口：读一遍，拗口的句子重写
- 画面和旁白有没有重复，或者互相打架
- 平台规范：敏感词、版权素材、广告标识
